# Supported formats

| Format | Scan | Read tags | Write tags | Artwork |
| --- | --- | --- | --- | --- |
| MP3 | Yes | Yes | Yes | Yes |
| FLAC | Yes | Yes | Yes | Yes |
| M4A/MP4 | Yes | Yes | Yes | Yes |
| WAV | Yes | Yes | Limited by container support | Limited |

Capabilities can vary with the installed Mutagen/container support. Musivex should report unsupported operations rather than silently dropping metadata.
